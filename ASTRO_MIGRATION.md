# Astro Foundation v1 — перечень изменений

1. Исходный `index.html` разделён на `Header.astro`, `index.astro`, `Footer.astro` и `BaseLayout.astro`.
2. Относительные пути `public/assets/` заменены на корректные публичные `/assets/`.
3. `styles.css` подключён через Astro layout, а `main.js` — через Astro script pipeline.
4. Сохранены тексты, классы, якоря, фотографии и стили из предоставленного архива.
5. Добавлены `package.json`, `astro.config.mjs`, `.gitignore`, инструкции запуска и публикации.
6. Никакие товарные страницы, переводы и фиктивные товары не добавлены.

## Перед использованием

- Выполнить `npm install && npm run build`.
- Сравнить главную страницу с исходной на широком и мобильном экранах.
- Проверить меню, переходы-якоря, картинки, контакты и console errors.
- На Cloudflare использовать отдельный preview deployment/ветку, не заменяя main до проверки.

Существующие `ARCHITECTURE.md` и `DESIGN_SYSTEM.md` перенесены без переписывания: архитектурный документ описывает прежнюю HTML-основу и должен быть актуализирован перед массовой разработкой.
